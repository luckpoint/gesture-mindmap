# ハンドトラッキングの検知候補

2026年10月23日。操作への割り当てを別途検討するための一覧。検知候補は実カメラでの精度を保証するものではない。

## 現在の構成

MediaPipe Hand Landmarkerで最大2手を認識する。各手の21点のランドマークと左右の手の推定を取得できる。現在は画像内の2D座標を使用しており、奥行きやworldLandmarksを操作には使っていない。

- 片手：手のひら中心の8方向移動でアクティブノードを切り替える。親指と人差し指のピンチでつかみ、手の移動でノードと子孫を動かし、指を開いて確定する。
- 両手：手のひら中心間の距離が増えるとズームアウト、減るとズームインする。
- 両手を検出したら片手操作よりズームを優先する。指の形やピンチの有無を開始条件にはしない。

## 片手の候補

| 検知対象 | 判定に使う情報 | 現状・検討事項 |
| --- | --- | --- |
| 上下左右・斜めへの移動 | 手のひら中心の変位 | 8方向選択・ピンチ移動で使用中 |
| 移動速度・スワイプ | 変位と経過時間 | 未実装。ゆっくりした移動と素早い払いを区別する |
| 静止・保持時間 | 座標や形が一定範囲内にある時間 | 未実装。微小な揺れの許容が必要。既存操作の開始時には安定待ちを使用 |
| グー／パー・開き具合 | 各指の関節角度や指先の位置 | 未実装。手の向きによる影響を確認する |
| 人差し指のみ・ピース・親指を立てる | 指ごとの曲げ伸ばし | 未実装。切り替え途中の形を誤判定しない工夫が必要 |
| 親指＋人差し指のピンチ | 指先間距離／手の大きさ | 実装済み。閉じる／開くで異なる閾値を使用 |
| 親指＋中指など別のピンチ | 対象となる指先間の距離 | 未実装。指の重なりと既存ピンチとの区別を確認する |
| 短いピンチ・長押し・連続ピンチ | ピンチの継続時間・回数 | 未実装。現在のつかみ操作との競合や単発の判定待ちが生じる |
| 画面内での手の傾き・回転 | 手首と指の付け根の方向 | 未実装。基準角と回転の連続性を扱う |
| 手のひら／甲・横向き | ランドマークから推定する手の面の向き | 未実装。3D情報の活用候補。真横では指が重なりやすい |
| カメラへ近づける／遠ざける | 見かけの手の大きさなどの時間変化 | 未実装。傾き・指の形との混同があり、カメラからの絶対距離とは扱わない |
| 円・往復などの軌跡 | 手の位置の時系列 | 未実装。開始／終了と通常移動の区別が必要 |
| 左手／右手の区別 | handednessの推定 | 片手の追跡リセット判定で使用中。人物識別や永続的な手のIDではない |

## 両手の候補

| 検知対象 | 判定に使う情報 | 現状・検討事項 |
| --- | --- | --- |
| 両手を広げる／近づける | 手のひら中心間の2D距離の変化 | ズームとして実装済み。左右・斜め・上下の間隔変化を扱う |
| 両手を同じ方向に動かす | 両手の中点の変位、距離の維持 | 未実装。ズームとの同時操作や優先順位を検討する |
| 両手を結ぶ線の回転 | 中心間ベクトルの角度変化 | 未実装。認識順の入れ替わりによる180度反転への対策が必要 |
| 両手それぞれのピンチ | 各手の指先間距離 | 未実装。片方のみ／両方のピンチを区別する |
| 片手で形を保持し、もう片手を動かす | 各手の形と移動 | 未実装。操作する手とモードを指定する手の役割を維持する必要がある |
| 両手の形の組み合わせ | パー＋グーなど各手の形 | 未実装。組み合わせ数より誤認識の少なさを優先して検討する |
| 両手の高さ・位置関係 | 各中心の上下左右関係 | 未実装。交差時の役割や画面の鏡像表示に注意する |
| 両手をそろえる・交差する・合わせる | 中心間距離と位置関係の時系列 | 未実装。手が重なると片手しか認識できなくなる場合があり、接触そのものを検出したとは扱わない |

## 両手ズームの実装仕様

- 各手の中心は手首と4本の指の付け根（ランドマーク0、5、9、13、17）の平均。指先を使わず、指の曲げ伸ばしの影響を抑える。
- 距離は画像幅を1とする単位で計算し、縦方向は画像の縦横比を補正する。検出結果の手の並び順には依存しない。
- 両手を100ms継続して認識してから開始する。その間は距離の基準を更新する。
- 基準からの距離変化が0.008未満なら反映しない。反映時の倍率は `exp(-距離変化 × 2.5)`。広げるほど縮小、近づけるほど拡大する。
- ズーム中心は表示中のキャンバス中央。既存の25〜200%の倍率制限と表示範囲制限を適用する。
- ノード移動中に両手へ切り替わると、未確定のノード移動を取り消してからズームする。ズームはノード編集履歴に追加しない。
- 片手に戻ったときは基準を破棄し、安定した開指から片手操作を再開する。残った手の位置で即座にノードを切り替えたりつかんだりしない。
- 両手中心間距離が0.05未満、不正座標、追跡消失では停止する。1秒超の認識間隔、時刻の逆行、距離の0.2超の急変では基準を取り直す。
- 編集・つなぎ替え・通常のポインタ入力などの最中は既存の入力抑止を適用する。

## 今後の検証・検討

ランドマークから判定できることと、意図して使いやすいことは別に評価する。現在の両手ズームの自動検証結果と実機手順は[検証記録](gesture-validation.md)を参照。

新しいジェスチャーを試す際は、操作に割り当てる前に検知状態・継続時間・変位を表示して確認するとよい。特に手の交差、片手の一時的な未検出、カメラとの距離変化、低い認識頻度での切り替えを確認する。

定型ポーズについては別機能のGesture Recognizerも選択肢となる。現時点では導入していない。
