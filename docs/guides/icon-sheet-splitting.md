# アイコン一覧画像を個別PNGに切り分ける

2026年10月24日に実施した「アイコンセット1.png」の分割手順。6列×12行の一覧画像から、文字と罫線を除いた72個のアイコンを作成した。

## 入力と出力

| 項目 | 内容 |
| --- | --- |
| 元画像 | `アイコンセット1.png`、1055×1491 px |
| 配列 | 6列×12行。左上から横方向に採番 |
| 個別画像 | `01_家.png` 〜 `72_ロック.png` |
| サイズ | 各128×112 px。絵柄は拡大・縮小せず中央配置 |
| 背景 | 白。透過処理は行っていない |
| 除外 | 上部タイトル、マス目の罫線、アイコン下の日本語ラベル |

初回の成果物はデスクトップの `アイコンセット1_分割/` と `アイコンセット1_72個.zip` に保存した。元画像と成果物はリポジトリには含めていない。

## 使用した方法

macOSのSwift、AppKit、Core Graphics、ImageIOで元画像を直接切り出す。画像生成や描き直しは行わず、元画像の線を保持する。PythonのPillowは未導入で、追加インストール時にネットワーク接続にも失敗したため、macOS標準の画像APIを使用した。

1. 元画像を確認し、列境界・行境界・文字の直前の高さをピクセル単位で指定する。
2. 各マスの左右と上端を5 px内側に寄せ、下端を文字より上に設定して切り出す。
3. 切り出した領域内でRGB各成分がすべて0.65未満の画素を調べ、その外接矩形を求める。値は0〜1で、白背景から黒い線を見つけるために使う。
4. 外接矩形の周囲に3 pxの余白を足す。元の切り出し領域の外には広げない。閾値は範囲の検出にだけ使い、画像自体を二値化しない。
5. 得られた画像を128×112 pxの白いキャンバス中央に配置し、連番と日本語名を付けてPNG保存する。
6. 全72個の一覧プレビューを作り、欠け・文字や罫線の混入・並び順を目視確認する。最後にZIP化して個数を検証する。

座標は画像の左上を原点とする。行の高さにはばらつきがあるため、単純な等分割ではなく次の設定を使用した。

```text
列境界 xs = [12,177,353,529,705,878,1043]
行境界 ys = [62,178,293,410,532,653,774,897,1019,1140,1253,1366,1478]
各行の切り出し下端 ends = [149,265,380,503,625,747,869,988,1110,1224,1340,1452]

行 r・列 c の切り出し矩形:
x = xs[c] + 5
y = ys[r] + 5
幅 = xs[c+1] - xs[c] - 10
高さ = ends[r] - ys[r] - 5
```

## 再実行

保存したスクリプトは [split-daily-icons.swift](../scripts/split-daily-icons.swift)。macOSとSwiftの実行環境（Xcode Command Line Tools等）が必要で、追加ライブラリは不要。リポジトリのルートで実行する。

```sh
swift docs/scripts/split-daily-icons.swift \
  "$HOME/Desktop/アイコンセット1.png" \
  "$HOME/Desktop/アイコンセット1_再分割"
```

出力先には新しいディレクトリ名を指定する。既存ディレクトリへの書き込みは拒否する。元画像の寸法が異なる場合も停止する。

出力は72個の個別PNGと、確認用の `preview.png`（768×1344 px）。プレビューを開いて全アイコンを確認した後、必要ならプレビューを出力フォルダの外へ移すと、ZIPに含まれるPNGを72個にできる。

```sh
open "$HOME/Desktop/アイコンセット1_再分割/preview.png"
mv "$HOME/Desktop/アイコンセット1_再分割/preview.png" \
  "$HOME/Desktop/アイコンセット1_再分割_preview.png"
ditto -c -k --sequesterRsrc --keepParent \
  "$HOME/Desktop/アイコンセット1_再分割" \
  "$HOME/Desktop/アイコンセット1_再分割.zip"
```

ZIP内の個別PNG数はPython標準ライブラリだけで確認できる。

```sh
python3 - <<'PY'
from pathlib import Path
from zipfile import ZipFile

archive = Path.home() / 'Desktop/アイコンセット1_再分割.zip'
with ZipFile(archive) as z:
    files = [n for n in z.namelist()
             if n.endswith('.png') and '__MACOSX' not in n]
    assert len(files) == 72, f'PNG数が不正: {len(files)}'
    assert z.testzip() is None, 'ZIPに破損があります'
print('72 PNGs verified')
PY
```

## 別の画像へ応用する場合

このスクリプトの座標と名前一覧は今回の画像専用。同じ寸法でも配置が異なる画像には、そのまま使用しない。列・行の境界、文字を除外する下端、名前と採番順を画像に合わせて変更する。行列数を変えるときはループ回数・検証条件・プレビューの寸法と配置も調整する。

絵柄が128×112 pxを超える場合は、余白を含めて収まるキャンバス寸法に変更する。淡い色や白い絵柄では今回の暗い画素による検出が成立しないため、背景との差分など別の検出条件が必要になる。

## 確認記録

初回は72個の一覧を目視し、アイコン全体が収まり、文字と罫線が除かれていることを確認した。ZIPに個別PNGが72個含まれることも確認済み。保存スクリプトでは入力・出力先を引数化し、確認用プレビューを出力先に保存するよう変更している。

保存したスクリプトも元画像で再実行し、個別PNGが72個・各128×112 px、プレビューが768×1344 pxになることを確認した。個別PNGは全72個について初回成果物とSHA-256が一致した。


## 日常生活アイコン72種ポスターの分割

同日、`Downloads/日常生活アイコン72種ポスター.png`（1055×1491 px）にも同じ座標・名前・キャンバス寸法を使用した。太陽・雪・Wi-Fiなど黒い輪郭のない絵柄があるため、保存スクリプトの検出条件を「RGBの全成分が0.65未満」から「いずれかの成分が0.65未満」に変更した。色付きの装飾も含めて範囲を検出し、画素そのものには加工を加えない。上記の初回SHA-256一致の記録は変更前のスクリプトについてのもの。

成果物はデスクトップの `日常生活アイコン72種ポスター_分割/`、`日常生活アイコン72種ポスター_72個.zip`、`日常生活アイコン72種ポスター_preview.png`。全72個のプレビューを目視確認し、文字・罫線が入らず絵柄が収まることを確認した。


## 人のアイコン72種の分割

同日、`Downloads/Cute Character Icon Catalog Grid.png`（1055×1491 px）を6列×12行に分割した。人物画像に合わせて座標と名前を設定した専用スクリプトは [split-character-icons.swift](../scripts/split-character-icons.swift)。元画像を直接切り出し、拡大・縮小せず128×112 pxの白いキャンバスに中央配置する。タイトル・罫線・日本語ラベルは除外する。

```sh
swift docs/scripts/split-character-icons.swift \
  "$HOME/Downloads/Cute Character Icon Catalog Grid.png" \
  "$HOME/Desktop/人のアイコン72種_再分割"
```

列境界は `[4,180,354,528,702,877,1051]`、行境界は `[71,186,304,423,543,664,785,906,1027,1147,1267,1380,1488]`、各行の切り出し下端は `[164,282,400,520,640,761,882,1003,1123,1244,1359,1466]`。各マスの左右を3 px、上端を2 px内側に寄せる。名前は左上から横方向に、`01_男の子_赤ちゃん1.png`〜`72_女性老人4.png`。

成果物はデスクトップの `人のアイコン72種_分割/`、`人のアイコン72種_72個.zip`、`人のアイコン72種_preview.png`。全72個のプレビューを目視確認し、11行目に残っていたラベル上端を除去するため下端を調整した。個別PNGが72個・各128×112 pxであること、ZIPに個別PNGのみ72個含まれ、破損がないことを確認済み。
